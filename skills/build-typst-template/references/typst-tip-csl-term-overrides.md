# CSL publication-specific term overrides

Read this only after setting the correct `default-locale` and observing that a
word generated by CSL still differs from the target. Override only that term in
the applicable language instead of copying its wording into bibliography data.

For example, when an English-language publication explicitly requires `p` and
`pp` without the periods supplied by the standard locale:

```xml
<locale xml:lang="en-US">
  <terms>
    <term name="page" form="short">
      <single>p</single>
      <multiple>pp</multiple>
    </term>
  </terms>
</locale>
```

Exercise both one-page and page-range records so the single and multiple forms
appear. Compare the emitted word, punctuation, and page data with the target.
Leave every unrelated locale term on the selected CSL default.
