# CSL default language

Read this before selecting or writing a CSL style. CSL means Citation Style
Language. Set the style's `default-locale` to the language required by the
target bibliography:

```xml
<style xmlns="http://purl.org/net/xbiblio/csl"
  version="1.0" class="in-text" default-locale="en-US">
```

This selects CSL's standard words and abbreviations when the style requests
them. For example, this page label plus canonical page data produces `p.` for
one page and `pp.` for a range under the standard `en-US` locale:

```xml
<label variable="page" form="short"/>
<text variable="page"/>
```

Keep only the range in the canonical page field, such as BibTeX
`pages = {65--69}`, rather than storing `pp. 65-69` as one literal. Compare
every word generated by the CSL style with the target. When the standard locale
agrees, retain it without additional term definitions.
